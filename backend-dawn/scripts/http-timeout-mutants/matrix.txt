# Hand-owned red sets for src/util/http.dawn's outbound contract: the request
# deadlines, how a timeout is classified apart from a refusal, and whether the
# client is really shared.
#
# `mutant|owner;;owner` -- the runner rejects a mutant that reddens anything
# other than exactly this set, and has no record mode.
#
# Timing assertions fail in two directions, so each deadline mutant is chosen to
# move only one of them. `inflate-deadline` is the important one: it leaves
# `.timeout(` in the source and only a timed request against a stalled peer can
# tell it from the real thing. `client-per-call` is its sibling for the shared
# client: the source still has one builder expression, and only the peer's view
# of the source port says whether the connection was reused.
#
# Since the outbound calls went behind the `Upstream` effect the owners split in
# two. What is about the SOCKET -- that a deadline reaches it at all, that one
# client is one connection -- is still owned by tests that stall a loopback
# peer, and those are the timing ones. What is about the CODE -- which budget a
# shape asks for, how a fault is worded and classified -- is owned by tests that
# install a handler and answer in microseconds. `transfer-tier-on-management`
# moved across that line: it used to be caught only by waiting ten seconds for
# `fetch`, and is now read off the request by two handlers, one of them the gc
# write-lock test in svc/files.
#
# The started/awaited pair rides on the same two functions the blocking calls
# do -- `request_for` puts the deadline on, `deadline_text` reads the fault back
# -- so it is held by these same mutants rather than by rules of its own. That
# is why "an async timeout reads exactly like a blocking one" is an owner of
# every mutant that moves the deadline or the wording: it asserts that whole
# chain end to end on the started path, which is what its name claims.
# `async-timeout-not-unwrapped` is the one question the blocking path cannot be
# asked. `Future.get` reports the fault wrapped in an ExecutionException, so the
# started path can lose the timeout on the way out with the deadline, the
# wording and the classifier all intact.
