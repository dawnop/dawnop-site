# Hand-owned red sets for the outbound-HTTP deadline assertions.
#
# `mutant|owner;;owner` -- the runner rejects a mutant that reddens anything
# other than exactly this set, and has no record mode.
#
# Timing assertions fail in two directions, so each mutant is chosen to move
# only one of them. `inflate-deadline` is the important one: it leaves
# `.timeout(` in the source and only a timed request against a stalled peer can
# tell it from the real thing.
collapse-transfer-tier|the two deadlines say what they are for
drop-deadline|a quiet peer hits the management deadline instead of blocking forever;;every request shape carries its deadline, whichever body handler it uses
inflate-deadline|a quiet peer hits the management deadline instead of blocking forever;;every request shape carries its deadline, whichever body handler it uses
mute-timeout-text|a quiet peer hits the management deadline instead of blocking forever;;only a timeout is reworded; every other fault keeps its text
transfer-tier-on-management|a quiet peer hits the management deadline instead of blocking forever
