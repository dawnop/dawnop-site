# 后台设置

`/admin/settings` 按后台、文件、上传链接、Paste 分组。分组独立保存；切换分组保留输入，离开页面时提示未保存的改动。加载失败时禁用编辑，保存失败时保留输入。

## 配置范围

| 分组 | 配置 | 生效范围 |
| --- | --- | --- |
| 后台 | 每页条数、紧凑列表 | 文章与 Paste 分页；后台表格密度 |
| 文件 | 上传/下载并发、存储配额、文本预览上限 | 文件管理；配额是用量展示的分母，不是上传硬限制 |
| 上传链接 | 默认期限、文件数、单文件大小、总大小 | 新建表单预填，创建时仍可调整；已发链接保持原额度 |
| Paste | 单条正文、单来源/全站提交频率与正文额度、存量上限 | 公开提交由后端执行限制；按 UTC 日期计日额度 |

上传链接管理的「默认额度」和 Paste 管理的「提交额度」都直接打开对应设置分组。
单条 Paste 的保留、删除、到期清理，以及已发链接的吊销、删除继续在管理列表操作。
目录、链接标签、内容与记录期限属于各条记录；侧栏折叠和拖拽列宽是当前浏览器的偏好。
七牛、登录和第三方服务凭据仍通过环境配置管理。

## 全局整数设置

`GET /api/settings` 返回已存值与默认值合并后的配置；`PUT` 支持部分更新。
所有字段先校验，再在同一 SQLite 即时事务内写入。非法值、非法组合或数据库写入失败均不留下部分改动。

| 新增键 | 默认值 | 范围 |
| --- | --- | --- |
| `admin_page_size` | 20 | 10–50 条 |
| `admin_compact` | 0 | 0 / 1 |
| `drop_expiry_hours` | 24 | 1–720 小时 |
| `drop_max_files` | 20 | 1–1000 个 |
| `drop_file_max_mb` | 100 | 1–5120 MiB |
| `drop_total_max_mb` | 1024 | 1–51200 MiB，且不小于单文件上限 |

已有四个文件设置键不变。新增设置无需迁移，未存值按默认值读取。
前端按登录会话缓存配置，保存成功后更新共享状态；登录变化清空缓存。
公开 Paste 的八个限制仍由 `/api/pastes/admin/settings` 管理并保存到 `paste_settings`，此次只集中设置入口。
正文容量以 KiB / MiB 显示，保存为整数 UTF-8 字节；已存的非整 KiB / MiB 值也可原样读取和保存。

## 验证

```bash
python3 backend-dawn/scripts/check-settings.py
python3 backend-dawn/scripts/contract_run.py
```

`check-settings.py` 在隔离 JVM/SQLite 中验证默认值、鉴权、上下限、严格整数、部分更新、写入失败回滚、并发交叉约束、重启持久化与已发链接额度不变；CI 在发布后端产物前执行。
