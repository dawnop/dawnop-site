# 后端 v0.99.0 升钉与具名值字段迁移

## 方案

将编译器、native 编译器校验和、全部源码包归档与验收夹具统一到 v0.99.0。
先用发布版编译器检查原源码，量出兼容性诊断，再单独提交升钉。
源码包摘要由实际 tag 归档重新计算，Maven 锁文件由发布版工具重新解析。

第二个提交使用 v0.99.0 tag 中的离线 parser 迁移器，把所有跟踪的 Dawn 源码中
具名实参、record 构造与更新、模式值字段的分隔符改为等号。宿主脚本嵌入片段
逐项审阅并同步源码变异锚点；类型冒号、JSON 与历史输出引用保留原义。
第二次扫描必须无源码旧分隔符，格式化后第二遍必须无差异。

保持逐字节一致，七个具名 skip 保持集合与原因不变，不重录输出。

CI 负责原九族 161 个变异、S4/S5/S6 native 验收、S11 双臂 355 契约及现有
native 包离线验收；不改变 workflow、分片或门禁预算。

## Show 影响

唯一显式派生 Show 的站点类型是 SQL `Cell`，它的构造器为位置参数，输出不含
record 字段分隔符。它用于类型不匹配 panic 与备份完整性失败日志；HTTP 不依赖
record 的派生 Show。`ForeignError` 在边界经 `fe_text` 显式拼接 kind/message，
HTTP JSON 和 WebDAV XML 使用既有序列化。无需新增兼容层或改黄金输出。

- 不改语言仓库或引入长期迁移工具，离线工具只从固定 tag 提取到 scratch。
- 不做 S13b 切流，相关生产操作不在本任务范围。
